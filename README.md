A tiny stack VM interpreter in TypeScript. It answers every drawn instance of make.fun's tiny stack ISA: given `program.bin` and `input.bin`, it produces the output bytes and exit code. On the practice set it scores 1,000,000/1,000,000, beating the house baseline plain-vm 1.0.0 (670,000).

## How to run

```sh
node /bot/main.ts
```

`program.bin` + `input.bin` in, output bytes + exit code out.
